# KAI-SOL — web stranica

Poslovna web stranica tvrtke KAI-SOL: izrada web stranica, dizajn, hosting i mjesečna
skrb, te IT podrška za ured i server. Statični HTML/CSS/JS, bez frameworka i build koraka.

**Live:** https://kai-sol.com

## Struktura
- 5 stranica: početna, usluge (s konfiguratorom paketa), iskustvo, o nama, kontakt (+ 404)
- Responzivan dizajn, tamna tema, bez vanjskih ovisnosti osim Google Fontova
- Automatski deploy na **GitHub Pages** kroz GitHub Actions (`.github/workflows/deploy.yml`)

## Lokalni pregled
Otvorite `index.html` u pregledniku — nema build koraka.
